# CLI

The `ailocalpack` CLI: framework and the general commands. Commands of a specific area are also described in that area's doc (`index`/`pack` in `docs/packs-and-registry.md`, `agent` and `gen` in `docs/generation.md`, `toolkit` in `docs/toolkit.md`, `github` in `docs/publishing.md`). Part of the product spec in `CLAUDE.md`: keep it current; record settled decisions in the matching section here.

## CLI

(`AiLocalPack.Cli`, `System.CommandLine` 2.x): `CliApp.Build(OsEnvironment)` holds the command tree; no command prints help (exit 0). `games list [--json]` scans Steam (with the library folders added / removed in `settings.json`), refreshes the catalog, detects engines and anti-cheats (`UpdateCatalog`) and prints it: a table (engine display name, anti-cheat name or `(allowed)`, local time; unavailable games marked) or JSON `{ libraries: [{path, available, addedByHand}], games: [{id, source: "steam"|"manual", appId (null for manual), name, buildId, engine (engine ID or null), antiCheat (ID, "none" or null), blocked, installPath, libraryPath, lastPlayed (UTC ISO 8601 or null), available}] }`. `toolkit detect <folder> [--json]` prints engine, confidence, marker, executable (ambiguous: the candidates) and `anti-cheat: <name> (<marker>)` / `none`, or JSON `{engine, name, confidence, marker, executable, ambiguous, candidates: [{engine, name, confidence, marker, executable}], antiCheats: [{id, name, marker}]}`; a missing folder exits 1. `toolkit scan-folder <folder> [--json]` prints each game (relative path or `.`, name, engine, executable, fingerprint, version file count, `steam: already in your library via Steam`), the skipped folders with reasons (`no-game`, `redistributable`, `installer`, `utility`, `saves`) and a too-large note, or JSON `{folder, games: [{path, name, engine, engineName, executable, fingerprint, version: {file: sha256}, inSteamLibrary, error}], skipped: [{path, reason}], limitReached}`; a game whose files can't be read gets `error` instead of an ID; file hashes are cached in `<cache>/file-hashes.json`; a missing folder exits 1. CLI output is English only (not UI resources). Tests run the built CLI as a child process (`CliRunner`, extra env vars; a throwaway `AILOCALPACK_HOME` unless one is given) against a `SteamFixture` tree (TestKit).
